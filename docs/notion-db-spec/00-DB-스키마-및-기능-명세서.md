## 핵심 의사결정 요약

| 주제 | 결정 |
|---|---|
| 이미지 저장 | DB가 아닌 Object Storage 사용 |
| DB 저장값 | 이미지 URL이 아닌 `storage_key` 저장 |
| AI 처리 | Redis/Celery 기반 비동기 처리 |
| 분석 요청 응답 | `202 Accepted`와 `job_id` 반환 |
| 분석 이력 | 결과를 덮어쓰지 않고 버전별로 누적 |
| 모델 추적 | `model_name`, `model_version` 필수 저장 |
| 앱 접근 | Flutter는 Backend API만 호출 |
| AI 접근 | 작업 메시지와 합의된 결과 형식만 사용 |
| 삭제 | 콘텐츠별 소프트/물리 삭제 정책 분리 |
