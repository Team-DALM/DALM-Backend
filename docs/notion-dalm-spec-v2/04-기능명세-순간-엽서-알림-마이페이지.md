# 04. 기능 명세 — 순간·엽서·알림·마이페이지

## HOME-01 오늘 탭

### 오늘 사진 없음

- 오늘 날짜와 감성 문구
- `오늘의 사진 남기기` 버튼
- 활성화된 과거 사진의 탐색 상태
- 최근 매칭 알림

### 오늘 사진 있음

- 4:5 사진
- AI 순간 제목
- 등록 시간
- 상태와 탐색 남은 기간
- 관리 버튼

### 매칭 발생

- 오늘 사진이면 카드 상태를 매칭 완료로 변경한다.
- 과거 사진이면 별도 매칭 알림 카드를 표시한다.
- 카드를 선택하면 매칭 결과 화면으로 이동한다.

## MATCH-04 결과 공개

| 표시 항목 | 정책 |
|---|---|

| 상대 사진 | 4:5 |

## MATCH-05 순간 관리

| 기능 | 처리 |
|---|---|
| 내 순간에서 숨기기 | 해당 사용자 목록에서만 숨김 |

## POSTCARD-01 엽서 작성 및 발송

| 항목 | 명세 |
|---|---|
| Endpoint | `POST /v1/matches/{match_id}/postcards` |
| 권한 | 매칭 참여자만 가능 |
| 입력 | 1~200자, trim 후 빈 문자열 불가 |
| 제한 | `(match_id, sender_id)`당 1회 |
| 검사 | 욕설·금칙어, 연락처·SNS 공유 경고 |
| 발송 후 | 수정·회수·재발송 불가 |
| 알림 | 상대에게 앱 내 알림과 푸시 |

### 발송 순서 정책

1. 먼저 사진을 등록한 사용자가 첫 엽서를 보낼 수 있다.
2. 나중에 사진을 등록한 사용자는 첫 엽서 수신 후 답 엽서를 보낼 수 있다.
3. 등록 시각이 같다면 사진 UUID 등 서버의 결정적 기준으로 순서를 정한다.

## NOTIFICATION-01 알림

| 종류 | 예시 문구 | 이동 화면 |
|---|---|---|
| `VALIDATION_PASSED` | 오늘의 순간이 탐색을 시작했어요. | 오늘 사진 |
| `PHOTO_REJECTED` | 다른 사진이 필요해요. | 거절 상세 |
| `MATCHED` | 당신과 나란한 순간을 발견했어요. | 매칭 결과 |
| `POSTCARD_RECEIVED` | 평행한 순간으로부터 엽서가 도착했어요. | 받은 엽서 |
| `SEARCH_EXPIRED` | 7일간의 탐색이 끝났어요. | 지나간 순간 |
| `SYSTEM` | 신고 결과와 서비스 안내를 확인해주세요. | 관련 화면 |

## SAFETY-01 신고

### 신고 대상

- 상대방 사진
- 받은 엽서
- 사용자

### 신고 사유

- 부적절한 사진
- 음란성·폭력성 콘텐츠
- 혐오·차별
- 개인정보 노출
- 광고·홍보
- 불쾌한 엽서
- 기타

### 처리

1. 신고 대상과 신고 사유를 검증한다.
2. 신고 레코드를 생성한다.
3. 신고자 화면에서 해당 콘텐츠를 즉시 숨긴다.
4. 누적 신고 콘텐츠를 관리자 검토 대상으로 올린다.
5. 처리 결과를 운영 알림으로 제공한다.
