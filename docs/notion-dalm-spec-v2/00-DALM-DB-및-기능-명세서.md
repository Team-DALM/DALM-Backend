## 핵심 정책 요약

> 💡 **하루 한 장, 최근 7일, 사진당 한 번의 매칭, 매칭당 각 사용자 한 장의 엽서**

| 정책 | MVP 결정 |
|---|---|
| 사진 등록 | 사용자당 하루 한 장의 활성 사진 |
| AI 거절 사진 | 일일 등록 제한에 포함하지 않음 |
| 사진 비율 | 4:5 고정 |
| 탐색 기간 | 등록 시점부터 최대 7일 |
| 매칭 대상 | 다른 사용자의 `SEARCHING` 사진 |
| 매칭 횟수 | 사진당 최대 한 번 |
| 매칭 제외 | 본인, 차단 관계, 이미 매칭된 사진 |
| 위치정보 | 사용·저장하지 않음, EXIF GPS 제거 |
| 엽서 | 매칭당 사용자별 최대 한 장, 1~200자 |
| 소셜 기능 | 공개 피드·좋아요·댓글·팔로우 없음 |
| 매칭 완료 후 | 재매칭 불가 |

## MVP 범위

### ✅ 포함

- 3단계 온보딩
- 카카오 로그인 및 프로필 생성
- 하루 한 장 사진 등록과 4:5 편집
- AI 사진 적합성 검사
- 최근 7일 사진 탐색 및 AI 매칭
- 탐색·매칭 상태 확인
- 매칭 결과와 AI 설명
- 순간 목록 및 상세
- 엽서 작성·수신·보관
- 매칭 전 사진 삭제
- 신고·차단
- 앱 내 알림과 푸시 알림
- 프로필·계정·알림 설정

### ❌ 제외

- 실시간 채팅
- 댓글과 좋아요
- 팔로우와 친구
- 공개 사진 피드
- 위치·거리 기반 매칭 및 지도
- 동영상과 다중 사진
- 사진 보정과 필터
- 매칭 상대 직접 선택
- 매칭 완료 후 재매칭
